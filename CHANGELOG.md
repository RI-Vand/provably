# Changelog

## 0.1.2
Safer SQL rewrite decisions, `.provablyignore` support, policy-aware route checks, bounded archive extraction, and expanded trust documentation.

## 0.1.1
Fixes hardened apps refusing to start on Windows: the repository now keeps `verified_core/` byte-for-byte (`.gitattributes`), and `provably-harden` does the same for the copy it places next to your app. Clearer README.

## 0.1.0
Pre-1.0: the tool names and arguments may still change.
First release: a local MCP server (`provably_protocol`, `provably_harden`, `provably_audit`, `provably_spec`, `provably_bizcheck`), the scanner and fixer for Python and JS/TS web stacks, and the verified decision core.
